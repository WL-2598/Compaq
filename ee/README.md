# 企业版（ee/）

## 规则（与[社区宪章](../docs/charter.md)一致）

1. **功能只增不减**：企业功能只能是新增模块，绝不能把社区版已有功能移入这里；
2. 本目录使用单独的商业许可证 `LICENSE-EE`；
3. 社区版（主目录）保持 MIT；
4. 授权方式：离线许可证文件（签名 JSON），不依赖在线校验；
5. 企业版修复的安全问题同步回社区版。

## 候选功能（按优先级，P2 立项）

1. LDAP / SSO 登录
2. 操作审计日志（导出 CSV）
3. 基于角色的权限控制（RBAC）
4. 合规报告模板（等保自查清单）

## 试点方案

- 找 3 家目标企业（中小型开发团队或学校实验室），免费试用 60 天；
- 换取需求访谈和案例授权；
- 签署试用协议时明确数据归属与保密条款（见 `docs/legal/hosted-service-checklist.md`）。
