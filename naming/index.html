    商标与命名方案（P0 最优先）

    状态：🟡 待人工检索。未解决前不做任何商业动作（收款、定价、签合同）。 本环境网络受限，无法访问商标局数据库，检索须由项目负责人完成。

    为什么

    "Compaq" 是惠普（HP）持有的知名商标（Compaq 1982 年创立，2002 年被 HP 收购）。继续以 Compaq 名义做商业化存在商标风险。建议：保留"康柏"作为社区昵称，正式名称换成与原商标无关的名字。

    候选名（三个）

    候选 含义 需检查
    RetroBox 复古 + 盒子/环境，直白好记 商标 / 域名 / GitHub 组织名
    KangHub "康"音译 + 中心，保留社区昵称的根 同上
    RetroNest 复古 + 巢/栖息地，偏社区感 同上

    三项检索（人工完成）

    1. 商标
    2. 中国：国家知识产权局商标查询 https://sbj.cnipa.gov.cn/
    3. 美国：USPTO TESS https://tmsearch.uspto.gov/
    4. 关键词：候选名 + 第 9 / 42 类（软件、SaaS），同时检索"康柏"在相关类别的在先注册
    5. 域名：候选名 + .com / .dev / .io 是否可注册
    6. GitHub：组织名或用户名是否可用

    改名后必须做的三件事

    1. README 顶部加入声明（草案）：

    本项目与 Compaq 或 HP 无关联，名称仅为致敬早期计算机文化。

    1. 仓库改名（GitHub → Settings → Repository name），GitHub 会自动重定向旧地址；
    2. 同步更新 README、docs、.github/FUNDING.yml、文档站、社交渠道与已发布内容。
