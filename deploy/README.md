## 架构（v0.1）

```
                 ┌─────────────────────────────┐
 用户浏览器 ───► │  compaq dashboard (:8642)   │  ← /healthz 供监控探活
                 │  + compaq run <n> --daemon  │
                 └─────────────┬───────────────┘
                               │ 挂载 volume
                 ┌─────────────▼───────────────┐
                 │  .compaq/instances/<name>/  │  配置 / 状态 / 备份
                 └─────────────────────────────┘
```

- **实例隔离（规划）**：每个付费用户一个独立容器（独立 volume 与进程），
  避免共享可写目录；v0.1 单容器多实例，仅限自用/内测。
- **每日备份**：`backup` 服务每天 03:00 执行 `compaq backup --all` 思路的脚本
  （见 `backup.sh`），保留 7 份滚动删除。
- **监控告警**：容器 `healthcheck` 打 `/healthz`；可用 Uptime Kuma 或
  Prometheus + Grafana 接同一端点（告警渠道：邮件 / Bark / Server 酱）。

## 快速启动

```bash
cd deploy
docker compose up -d
open http://localhost:8642
```

首次启动会创建 `demo` 实例并写入状态，仪表盘立即可见画面。
