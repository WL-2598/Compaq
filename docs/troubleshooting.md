# 故障排查

!!! info "待首个版本发布"
    本页将收录按症状分类的排查路径：启动失败、性能过低、插件冲突、网络问题等。

## 规划中的排查路径

| 症状 | 先检查 | 文档 |
|---|---|---|
| 启动失败 | 日志位置、依赖版本 | 待补充 |
| 旧机器上太慢 | 内存/磁盘限制、可关闭的特性 | 待补充 |
| 插件不生效 | `plugin.json` 兼容范围、入口文件 | 见 `registry/` 规范 |
| 升级后行为变化 | [CHANGELOG](https://github.com/WL-2598/Compaq/blob/main/CHANGELOG.md) 的 Changed / Fixed | 待补充 |

仍未解决 → 开 Issue（用 Bug 模板，附版本号与环境信息）。
