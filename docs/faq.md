# 常见问题（FAQ）

## 这个项目和惠普的 Compaq 是什么关系？

没有关系。名称仅为致敬早期计算机文化；商标检索与改名进行中，见 [命名方案](naming.md)。

## 社区版会收费或闭源吗？

不会。[社区宪章](charter.md) 承诺：社区版永不闭源（MIT），功能只增不减。收费只发生在托管服务与企业版**新增**功能上。

## 我能用它做什么？

规划中的能力见 [首页](index.md)。项目处于 pre-alpha，可运行版本尚未发布，请关注 [路线图](roadmap.md)。

## 如何赞助项目？

仓库顶部的 Sponsor 按钮，三档 ¥15 / ¥50 / ¥500。资金每季度公开报告。

## 遇到问题怎么办？

先搜 Issue；Bug 用 Bug 模板；**安全问题请按 [安全策略](https://github.com/WL-2598/Compaq/blob/main/SECURITY.md) 私下上报**。
