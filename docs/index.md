# 欢迎来到康柏（Compaq）文档

**康柏是一个复古计算环境项目**：让任何人都能在旧机器或容器里一键跑起完整的复古计算环境，并通过插件扩展能力。

!!! warning "当前状态"
    项目处于预开发（pre-alpha）阶段：治理与文档地基已就绪，可运行版本尚未发布。进度见 [路线图](roadmap.md)。

!!! note "命名声明（待办）"
