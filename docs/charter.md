# 社区宪章

## 我们的承诺

1. **社区版永不闭源**：主仓库代码始终以 MIT 许可证公开。
2. **功能只增不减**：社区版已有功能不会被删除或移入付费版；企业版（`ee/`）只能新增模块。
3. **透明**：每季度公开财务报告（`docs/finance/`）；重大决策公开讨论。
4. **独立**：本项目与 Compaq、HP 公司无关联，名称仅为致敬早期计算机文化（改名后此声明将固定在 README 顶部）。
5. **对读者有独立价值**：对外内容必须是教程、踩坑、设计决策，而不是纯粹的"求 Star"。

## 边界

- 商业动作（定价、合同、收款主体、公司形式）由项目负责人确认，治理机构提供材料与建议；
- 许可证变更、社区版功能删减属于重大事项，需 2/3 维护者同意并公示 2 周（见 [GOVERNANCE.md](https://github.com/WL-2598/Compaq/blob/main/GOVERNANCE.md)）。

## 收入结构红线（自我约束）

- 任何单一收入来源占比不超过 40%；
- 任何单一客户占比不超过 30%；
- 若咨询收入占比超过 40%，说明产品化不足，应减少定制项目，把重复需求做成功能。

## 修订

本宪章的修订需要公开讨论至少 2 周，并经 2/3 维护者同意。
