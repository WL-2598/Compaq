# 架构说明

!!! info "待首个版本发布"
    首个可运行版本发布后，本页将包含：组件总览图、数据流、插件加载机制、与托管版（康柏 Cloud）的边界。

## 规划中的架构原则

1. **旧机器优先**——默认配置面向低内存、慢磁盘的硬件做取舍；
2. **容器友好**——社区版与托管版共用同一套 Docker Compose 模板（托管版只叠加账号、备份、监控）；
3. **插件隔离**——插件通过 `plugin.json` 声明兼容范围，加载失败不得拖垮主进程；
4. **企业功能外置**——`ee/` 目录只放新增模块，核心永远在社区版。

架构决策以 ADR（Architecture Decision Records）形式沉淀在 `docs/adr/`（随首个版本建立）。
