# Compaq（康柏）

**一句话定位**：康柏是一个复古计算环境项目，目标是让任何人都能在旧机器或容器里一键跑起完整的复古计算环境，并通过插件扩展能力。

## 规划中的核心能力

1. **一键复古计算环境**——在旧机器或容器中直接启动，无需手工拼装模拟器与镜像。
2. **插件系统**——通过 `plugin.json` 描述的插件扩展环境能力，社区以 PR 提交到注册表（见 [registry/](registry/)）。
3. **部署与配置实战**——Docker Compose 模板与配置参考，覆盖从笔记本到家庭服务器。
4. **托管版（康柏 Cloud）**——一键部署、每日备份、基础监控与告警（规划中，见路线图 P2）。
5. **故障排查与性能调优**——面向老旧硬件的文档与工具。
